# Layali | ليالي

An Arabic-first Android app for browsing and booking services published by providers.

## Project status

- Bundled demonstration venues, reviews, member profiles, chats, and showcase offers have been removed.
- City names remain as navigation filters; local venue counts are no longer claimed.
- Listings and user-generated content appear only when supplied by the connected Firestore project.
- The app does not bundle demo sign-in accounts or invent email addresses for local sessions.

## Build

Open the project in Android Studio and build the `app` module. Firebase configuration is supplied by the project's environment; do not commit production credentials.
